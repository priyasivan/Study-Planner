# 📚 Study Planner Web App

A simple and user-friendly Study Planner Web Application that helps students organize their study tasks and track their daily progress.

## ✨ Features

* Add new study tasks
* Mark tasks as completed or undo
* Delete tasks
* View total, completed, and pending tasks
* Track study progress using a progress bar
* Save tasks using Browser Local Storage
* Press Enter to add tasks
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Start managing your study tasks!
